# 100 Days of Rust

**Learn Rust by building a real todo app.** A 100-day, beginner-friendly
course that takes you from an empty folder to a complete application — a CLI,
a REST API, a server-rendered web UI, and a terminal UI — then takes the same
app to production and goes underneath with data structures and algorithms.

- **Days 1–60:** build the app: Rust basics, ownership, testing, async,
  SQLite, CLI, API, web UI, TUI, security, and deployment.
- **Days 61–90:** production ground: Podman, PostgreSQL, Redis, Kafka, gRPC,
  WebSockets, Kubernetes, LocalStack, microservices, distributed systems,
  observability, performance, and supply chain.
- **Days 91–100:** data structures and algorithms, measured with `criterion`.

All 100 days are written and verified. The site is free, has no sign-up, and
installs as an offline app.

**Read it at [pratirupm.github.io/100-days-of-rust](https://pratirupm.github.io/100-days-of-rust/)**

## What's inside

| Path | What it is |
| --- | --- |
| `CURRICULUM.md` | The full 100-day plan: day, lesson, app change, tests, tag |
| `src/chapters/` | The lesson sources — edit these, then `bun run days` |
| `src/content/docs/` | The site pages, including the generated day pages |
| `src/content/docs/appendices/` | The finished app, file by file; and where to go next |
| `tools/` | Generators and gates — prose lint, quote and transcript checks, icons |
| `containers/validator/` | The pinned Podman image used to build and test the app |
| `STYLE.md` | The house style every lesson follows |
| `VALIDATION.md` | What was checked, in which container, and when |

## Run it locally

```bash
bun install
bun run dev        # http://localhost:4321/100-days-of-rust/
```

`bun run build` emits the static site — with an offline service worker, a
search index, and the PWA manifest — to `dist/`.

## The gates

`bun run check` runs the prose lint, verifies every quoted code block against
the reference application, checks every terminal line against captured runs,
and builds the site.

The reference app lives in a sibling repository (`../rust-todo-app`) and is
built in Podman. The host never needs Rust installed. See
[`VALIDATION.md`](VALIDATION.md) for the commands.

## Written by an AI

The prose, the curriculum, and the explanations were generated by an AI
assistant; every command and every transcript in the book was executed and
verified for real inside a pinned container. The
[disclaimer](https://pratirupm.github.io/100-days-of-rust/disclaimer/)
explains exactly what that means.
