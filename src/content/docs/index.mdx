No programming experience needed: you'll learn **Rust** by building a real
**todo app** — a command-line tool, a REST API, a browser interface, and a
terminal UI — one small piece a day, with tests that keep the code honest.

<div id="tracker-overview"></div>

## Build a real todo app in Rust

Over the first 60 days you write a complete application from an empty folder:
a **CLI** with `clap`, a **REST API** with `axum`, a server-rendered **web
UI** with `askama`, a **terminal UI** with `ratatui`, and a **SQLite** data
layer with `sqlx` — plus the tests, authentication, security work, and
deployment that hold it all together. Every command and every line of output
comes from a real run of the finished app.

## Go past the app

Days 61–90 take the same app to production: Podman containers, PostgreSQL,
Redis, Kafka, gRPC, WebSockets, Kubernetes, and a local cloud with
LocalStack. Days 91–100 go underneath with data structures and algorithms,
measured with `criterion` and tied back to the app.

## Learn Rust from zero

The course assumes no programming experience. You start with your first
failing test and end with a released application: structs, enums, ownership,
borrowing, traits, generics, lifetimes, async, SQL, HTTP, sessions, and
observability — each introduced exactly when the app needs it.

## Git from Day 1

Every day ends with a save point: `git add`, `git commit`, and a tag at the
end of each part. You finish with a real project and a history, not just a folder — and
you can always go back to a state that worked.

## Frequently asked questions

**Is this Rust course free?** Yes — the whole book is free to read online,
with no sign-up and no account.

**Do I need programming experience?** No. The course starts from an empty
folder and assumes nothing beyond a terminal, an editor, and Rust 1.99 or
newer.

**What will I build?** A complete todo app in Rust: a command-line tool, a
REST API, a server-rendered web UI, and a terminal UI — with SQLite, tests,
authentication, and deployment. Then the same app goes to production with
PostgreSQL, Redis, Kafka, gRPC, WebSockets, and Kubernetes.

**Do I need to know git?** No. Git is taught from Day 1: every day ends with
a save point, and the course builds the habit one commit at a time.

**How long does the course take?** About two to four hours a day. The first
60 days build the app; days 61–90 cover production ground; days 91–100 cover
data structures and algorithms. All 100 days are written and verified.

**Is this book really written by an AI?** Yes. The prose is machine-written;
every command and transcript in it was executed and verified in a container.
The [disclaimer](/100-days-of-rust/disclaimer/) explains exactly what that
means.
